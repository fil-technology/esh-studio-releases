On-device MLX text models

Esh Studio can now run large MLX text models on your Mac through esh — including Qwen3-30B-A3B (4-bit). Pick an MLX model in the chat model picker and generate; responses stream in, attributed to the exact on-device model.

  • Zero-setup runtime — on first use esh provisions an isolated Python runtime with mlx-lm automatically. No Homebrew, no Anaconda, no global pip, no duplicate downloads, and no app restart.
  • Honest readiness — a model's memory fit is reported separately from whether its MLX runtime is ready; esh refuses a model with a clear error rather than pretending it can run.
  • Streaming, cancellation & recovery — Stop halts a run immediately and frees the worker's memory.

Apple Intelligence and local GGUF models work exactly as before. Your saved conversations are untouched.
